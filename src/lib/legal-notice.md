Service-role backend processes can bypass ordinary client row restrictions. A brokerage provider connection secret is stored server-side and is not the same as your brokerage password. This notice does not claim that administrators cannot access it or that it is protected by field-level encryption.

Privileged human access is permitted only for legitimate support, security, maintenance or legal needs and must be limited to what is necessary. This is an operating restriction, not a representation that every privileged database read has a complete audit trail. Never send a password or authentication code to an administrator.
